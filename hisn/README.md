# حِصن | HISN — الإصدار التمهيدي 0.3

حزمة مصدرية أولية لتطبيق دعم فني ومشاهدة شاشة iPhone على OPPO بموافقة صاحب الجهاز. ليست نسخة بث مكتملة.

## ما تتضمنه
- واجهة Android أولية بالعربية.
- هيكل Gradle لبناء APK.
- خادم WebSocket تجريبي لتنسيق الاتصال.
- إعداد GitHub Actions لبناء APK تلقائياً.
- وثائق المعمارية والخطوات التالية.

## حدود iOS
لا يمكن للتطبيق إخفاء مؤشر مشاركة الشاشة أو تجاوز موافقات iOS. الاقتران المحفوظ لا يمنح إذناً دائماً للبث. يمكن إعادة اتصال WebRTC تلقائياً فقط إذا بقيت جلسة ReplayKit الأصلية نشطة.

## الحالة
واجهة Android وخادم الإشارة نماذج أولية فقط. لا يوجد بث WebRTC فعلي، ولا اقتران دائم، ولا تطبيق iOS مكتمل في هذا الإصدار.

## بناء APK
من GitHub افتح Actions وشغّل Build HISN Android APK. بعد نجاح المهمة نزّل artifact باسم hisn-debug-apk. هذه النسخة تعرض الواجهة فقط ولا تعرض شاشة iPhone حتى يتم تنفيذ WebRTC وتطبيق iOS.
